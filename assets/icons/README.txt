Example icon art for the Memory Examination examples screens.

Drop one image per square here, named after its id, and let Godot import it:
  EX1-1.png .. EX1-5.png  = covered examples (screen A)
  EX2-1.png .. EX2-4.png  = NOT covered examples (screen B)
(.png, .webp, .svg or .jpg). Square = 64x64 px on the 960x540 layout; 128x128 or larger art looks best.
When a file exists, its square shows the art instead of the placeholder outline + label.
Alternative: set a path per id in MemoryExam.ICON_ART (data/memory_exam.gd).
